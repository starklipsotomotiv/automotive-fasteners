# Automotive Fasteners

## Product Range

- Metal fasteners
- Plastic fasteners
- Retaining clips
- Push-type fasteners
- Panel fasteners
- Trim fasteners
- Assembly clips
- Retainers
- Fixing components

Our fastening solutions are used in:

- Trucks and buses
- Interior trim systems
- Exterior trim systems
- Door assemblies
- Body panels
- Bumpers
- General automotive assembly applications
